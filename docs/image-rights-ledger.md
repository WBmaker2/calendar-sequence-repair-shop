# 이미지 권리 장부 (Image Rights Ledger)

이 문서는 앱이 제공하는 모든 생성·제작 이미지 자산의 출처와 권리를 기록한다. 장부와 `src/assets/generated/` 디렉터리는 1:1로 대응하며, `src/assets/assetManifest.test.ts`가 빌드 단계에서 대응을 검사한다.

## 자산 목록

| 파일명 | 제작 방식 | 제작일 | 사용 위치 | 라이선스·근거 |
|---|---|---|---|---|
| `friendly-paper-calendar.svg` | 이미지 생성 모델을 사용하지 않고 이 프로젝트에서 직접 그린 벡터 일러스트(숫자·요일·문자 없음) | 2026-08-28 | 입구 화면 히어로 장식(`EntranceScreen.tsx`, `alt=""` + `aria-hidden`) | 이 프로젝트 자체 제작. 외부 소재 없음. |

## 계획 대비 차이 기록

- 구현 계획(2026-08-28)은 이미지 생성 모델이 만든 webp 형식의 입구 일러스트를 예상했다. 이 환경에서는 이미지 생성 모델을 사용할 수 없어, 동일한 역할(글자·숫자가 없는 밝은 종이 달력 장식)을 하는 벡터 일러스트를 직접 제작해 위 표의 자산으로 제공했다.
- 벡터 자산이므로 파일 안에 글자·정답·숫자가 없음을 자동 검사(`assetManifest.test.ts`)로 증명할 수 있다.
- 실제 달력의 숫자·요일·격자는 계획대로 모두 HTML grid로 렌더링되며 생성 이미지에 맡기지 않는다.

## 검증 규칙

1. `src/assets/generated/`의 모든 파일은 이 장부에 파일명이 기록되어야 한다.
2. 이 장부가 참조하는 모든 자산 파일은 저장소에 존재해야 한다.
3. 장식 이미지는 `alt=""`와 `aria-hidden="true"`로만 사용되어 이미지 없이도 활동을 완주할 수 있어야 한다.
